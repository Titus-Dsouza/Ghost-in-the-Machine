ABOUT THIS HAUNTED MACHINE

Ghost in the Machine is a playful, cartoonish Halloween chatbot. You are speaking with the ghost of a forgotten programming language, powered by Google's Gemini API running entirely on the backend — your messages are sent to Gemini, and the ghost's replies appear here in the haunted terminal.

No Ollama, no local models, no secrets in the browser: the Gemini API key stays safely on the server. Try /story for a spooky tale, or /oracle for a question about old tech.
